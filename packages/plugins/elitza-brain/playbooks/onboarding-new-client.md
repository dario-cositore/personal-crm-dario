# Onboarding a new client

## Right after "yes"

1. Send the payment link (50% upfront).
2. Send the diagnosis note back to them for confirmation.
3. Book the build slot (2-4 working days).
4. Ask for: credentials, sample documents, access to their tools.

## Before you build

- Collect 5-10 real examples of the input and the desired output.
- Confirm the out-of-scope list in writing.
- Confirm who approves the final result.

## First day of the build

- Set up the environment on their credentials.
- Build the first flow end to end with one real case.
- Show them the result. Adjust.

## Before delivery

- Run 10 real cases through it.
- Fix what breaks.
- Write the one-page operating note.
- Generate the handover document.

## Delivery

- Walk through it live (30 minutes).
- Hand over credentials.
- Record the payment (remaining 50%).
- Set a 7-day check-in.

## 7-day check-in

- Did it run without you?
- What broke?
- One small tweak, included.
- Ask for a testimonial or referral.
