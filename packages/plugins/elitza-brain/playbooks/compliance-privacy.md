# Compliance and privacy

## GDPR

- Process data only for the stated purpose. No reuse without consent.
- Data minimisation: collect only what the flow needs.
- Right to erasure: the client must be able to delete a contact and their data.
- Data processing agreement (DPA) if you process personal data on their behalf.
- Store credentials in mode-600 files, never in code or logs.
- Never write secret values into handover documents.

## AI Act (EU)

- Classify the system: most AI Enablement work is limited or minimal risk.
- High-risk systems (hiring, credit, healthcare) need conformity assessment.
- Transparency: tell the end user when they are talking to an AI.
- Keep a simple technical documentation file per system.

## Data handling in delivery

- Use the client's own credentials and accounts, not yours.
- Prefer self-hosted or EU-region SaaS for EU clients.
- Log only what is needed. Retention policy in the handover.
- Back up client data on their infrastructure, not yours, unless agreed.

## Outreach compliance

- Public-listing reason in every first touch.
- Opt-out line in every email.
- Honour opt-outs immediately and record them.
- No scraping of personal email; use public business addresses only.
